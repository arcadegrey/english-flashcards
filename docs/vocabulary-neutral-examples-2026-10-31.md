# 例句题材中性化（2026-10-31）

根据用户要求，移除活动词库例句与学习提示例句中的政治人物、政党、意识形态立场、政治事件及相关战争叙事。用户明确选择：词义本身涉及政治的词仍保留，例句只用于拼写、发音或词义学习，不讲政治人物与事件。

publicly（ID 6459）的默认例句改为：

> She thanked the team publicly.
>
> 她公开感谢了团队。

## 本批范围

- 413 个活动词条调整例句字段：408 条默认例句、5 条多义项附加例句；ID、词头、释义、音标、分类和其余词条保持原样。
- 256 组学习提示改写其中的 397 条双语例句。原来演示政治场景的普通词改为学校、家庭、运动、工作或自然场景。
- communist、political、marxism 等词条保留原释义，明确使用拼写、读音、词义学习句。这是用户指定的呈现方式，不把这类语言练习当作自然场景使用例句。
- 题材筛查覆盖活动词条的默认例句、多义项例句以及实际编译出的学习提示例句；进行主题词、中文叙事线索、政治专名及军事场景复核。
- 多义词按真实语境复核：cabinet 的橱柜、colony 的动物群体、revolution 的旋转、diplomatic 的得体表达等保留非政治义。筛查白名单是完整双语句对，不是允许整个词或任意后续文本通过。
- 词性或提示范围随例句义项变化时一并调整，例如 colony 的动物群体、combat 的日常对抗压力。原始 before 快照及历史编辑阶段仍保留，方便审校和兼容。

## 数据与历史

完整 before／after、例句编辑表、提示编辑表、逐句非政治判定和筛查规则在 `data/vocabulary-neutral-examples/`。`scripts/apply-vocabulary-neutral-examples.mjs` 先校验整个基线及全部实际完整分片，再写入，未知修改会被拒绝。

活动 canonical、core、完整 TOEFL／IELTS 分片、按需例句、词库摘要、阅读查词摘要和提示批次一起更新。学习提示编译器输出新的哈希路径，旧浏览器缓存不会被当成新词库数据。

`beforeNeutralExampleReview` 能完整还原前一编辑阶段；原有编辑脚本不会回滚本批。旧作业、测验及听写成绩按原快照继续评分，保留兼容所需的旧音频和服务端听写登记。不操作个人账户、自定义词库、学习进度、收藏或其他个人记录，不需要 D1／个人数据迁移。

用户历史记录中的原始文字不被改写；本批清理的是活动公共学习内容。原始编辑证据中的旧句不作为新默认例句分发。阅读文章正文不是词卡例句，本批没有改写已有阅读文章。

## 验证入口

```bash
node scripts/apply-vocabulary-neutral-examples.mjs
node scripts/audit-neutral-examples.mjs
npm test
npm run build
```

`audit-neutral-examples.mjs` 对所有活动词卡和提示例句扫描。只有显式词汇学习语境中的引号目标词可以作为语言对象出现；普通叙事不能依赖引号或词白名单绕过。剩余命中必须有完整双语句对的逐句复核记录；存在未处理候选时命令失败。

本机既有 Kokoro 模型生成器为 `scripts/generate_neutral_example_audio.py`，支持按精确文本哈希断点恢复；验证与发布命令为 `scripts/validate-neutral-example-audio.py`、`scripts/publish-neutral-example-audio.py`。没有引入新的 API key 或在线合成服务。
