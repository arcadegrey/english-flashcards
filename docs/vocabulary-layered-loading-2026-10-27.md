# 词库基础信息与例句分层加载（2026-10-27）

继续优化 `5e0d8af` 的首次学习等待。活动词库仍为 8699 条，词条、稳定 ID、释义、音标、中英文例句、音频文本和账号数据均未修改。

## 当前加载方式

- 首页、分类、历史词恢复和收藏先读取轻量目录。目录保留原有全部基础字段、分类、Level/List 和 aliases，将 `example` / `exampleCn` 拆成独立数据。
- 全范围学习、测验、拼写和配对仍使用完整 8699 词的基础池；不会只从当前几十词中抽题或生成干扰项。
- 词卡及阅读单词弹窗按稳定 ID 和精确词头加载对应例句组，每组最多 50 个活动词。当前词加载完成后，只为学习/集合中的下一词预取详情；预取失败不阻止当前学习。
- “学习提示”在展开时才下载既有提示批次，完整内容、高亮和引用沿用原实现。例句和提示分别缓存；打开词卡不等于所有提示已离线保存。
- 填空资格在构建时使用原来的挖空函数判定。运行时从同一资格范围抽题，再只读取当前题目的例句；详情加载期间不开放作答，不新增成绩或改变题目。题干、干扰项和评分保留原逻辑。
- 例句未完成时显示现有卡面内的加载状态；失败时保留词义并提供重试，恢复联网会自动重试。快速切词或关闭页面后，旧响应不能覆盖新词内容。

## 缓存与兼容

- 新目录和例句批次使用内容哈希文件名，写入原有公共词库版本缓存。`vite.config.js` 排除这两个派生目录的重复哈希，原始词库及原有分片仍决定内容版本。
- 已缓存的旧完整 core / List / 扩展词库 / 整库可复用；读过完整轻量目录后，后续历史词、复习和收藏也直接复用已保存的基础池，不要求重新下载对应 List。
- 已访问或预取的例句组可离线读取；未缓存组离线时保留基本词义并显示重试。没有保证全部例句、提示或音频均已离线下载。
- 自定义词和退役词保持自己的内联例句。不能仅凭拼写给另一个 ID 附加例句，同形词记录继续独立。
- 原有 `loadVocabulary`、`loadFullVocabulary` 和 List 完整数据接口保留；老师进度页等旧调用继续取得完整记录。App 学习流明确改用新的 Catalog 接口。
- 新增的传输标记只存在于公共目录，不进入用户进度、收藏、作业或成绩快照。没有账户存储格式、Worker、D1 或云同步协议变更。
