# 账号弹窗深色适配（2026-10-27）

截图问题由硬编码浅色底与深色主题文字混用造成：统计卡仍为浅蓝/浅绿，登录注册切换底仍为浅蓝，数字和标签已经变为浅色，导致对比度不足。

## 修改

仅在 `src/styles/auth.css` 增加 `.dark` 下的账号组件样式：

- 统计卡、登录/注册底栏、输入框和注册身份选择复用既有 `--ds-dark-inset` / `--ds-dark-raised`。
- 收藏链接、选中切换和身份标签复用 `--ds-dark-link`，数字和正文继续使用共享文字 token。
- 登录后的班级入口、同步图标、成功/失败提示、退出链接以及弹窗悬浮样式补齐深色适配。蓝、绿、红保持原有产品/语义用途。
- 浅色模式原样保留；布局、组件、登录注册处理、验证码、账号隔离、存储、云同步与学习行为均未修改。
