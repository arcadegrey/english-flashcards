## 内容与来源

- 中文解释、辨析说明和双语例句由本项目原创编写；参考资料用于事实核对，不导入词典原文或例句，也不假定获得第三方词典内容的转载许可。
- 每组内容记录适用词义、来源 ID、核对日期和 source-checked 状态；这一状态表示本轮已核对公开词条／语法资料，不表示经过独立语言专家审校或官方认证。
- 每条适用词义单独注明词性及范围，近义词不能脱离语境一概替换。多义词例如 kind 仅比较“待人友善”的形容词用法，不套用在“种类”的名词义。
- 构词区分“本词构词”与“词族拓展”。例如 helpful 展示 help + -ful；help 展示其派生词 helpful 的构成，不声称 help 自身可按固定字母位置拆开。
- 本批侧重英语词基与常见前后缀，不编造拉丁／希腊词源。没有核验的构词资料时省略构词项。
- 形容词 friendly、否定前缀 im-、easy → easily 的拼写变化均有明确说明，不能套用“所有 -ly 都是副词”等机械规则。

## 实现与兼容

- src/data/coreWordNotes.js 保留并汇总首批 30 词，src/data/dailyWordNotes.js 保存新增 70 词；对外导出不变。通过标准化英文拼写匹配，不依赖可能变动的词 ID，不修改词库原文、音频、用户进度或学习行为。
- 现有 WordCard 的“显示提示”消费结构化内容；每组显示适用范围、辨析、原创例句和可点击的参考链接。look/see/watch、hear/listen、bring/take、come/arrive、tired/sleepy、new/recent、common/ordinary 标为“易混词辨析”，不伪装为可直接替换的近义词。词头、构词公式和例句目标词继续加粗；未覆盖词保留基础提示。
- 来源链接使用新窗口及 noopener/noreferrer；收起提示时使用 aria-hidden 和 inert，防止隐藏的链接进入键盘焦点和辅助阅读顺序。
- 内容随前端打包，加载应用后查看提示无需额外请求或联网；外部参考网页需要网络。
- 不新增 API、数据库结构、用户数据字段或迁移；发布前端即可生效。

## 后续扩充规则

1. 从现有基础词库选词，明确具体词义、词性和比较范围；无自然的近义／易混关系时写单词用法，不强配搭档。
2. 核验近义关系、用法和构词；说明资料不足的部分，保持 draft 状态，不填充猜测。
3. 编写原创中文辨析或具体用法及两条双语例句，登记来源与核对日期，再改为 source-checked。单词用法使用 comparisonType: usage、单个 words 条目，通过现有提示区域显示“用法提示”。
4. 将词映射到词组及可选构词资料；确保构词的 base/derived 与本词匹配。
5. 纯内容扩充只做针对内容的完整性、来源、词形匹配及未核验不展示校验，再构建一次；不默认运行全量测试或多端浏览器验收。若改动提示渲染，只补必要的对应检查。
