# 核心词学习提示（100 词，2026-10-23）

## 范围

当前覆盖现有词库的 100 个常见基础词，提供 56 组辨析（49 组近义词、7 组易混词），其中 47 个词接入 38 组构词／词族说明。由 30 词试点新增 70 词，覆盖常见动作、沟通、情绪、外貌、时间和学习场景。

选词依据日常基础用法和可核验的关系，不宣称是权威词频排名前 100 名。reply、purchase 等日常用词在原词库中可能仅挂 IELTS 分类；提示按英文拼写匹配，不改变既有分类、词 ID 或学习范围。

## 内容与来源

- 中文解释、辨析说明和双语例句由本项目原创编写；参考资料用于事实核对，不导入词典原文或例句，也不假定获得第三方词典内容的转载许可。
- 每组内容记录适用词义、来源 ID、核对日期和 source-checked 状态；这一状态表示本轮已核对公开词条／语法资料，不表示经过独立语言专家审校或官方认证。
- 每条适用词义单独注明词性及范围，近义词不能脱离语境一概替换。多义词例如 kind 仅比较“待人友善”的形容词用法，不套用在“种类”的名词义。
- 构词区分“本词构词”与“词族拓展”。例如 helpful 展示 help + -ful；help 展示其派生词 helpful 的构成，不声称 help 自身可按固定字母位置拆开。
- 本批侧重英语词基与常见前后缀，不编造拉丁／希腊词源。没有核验的构词资料时省略构词项。
- 形容词 friendly、否定前缀 im-、easy → easily 的拼写变化均有明确说明，不能套用“所有 -ly 都是副词”等机械规则。

## 实现与兼容

- src/data/coreWordNotes.js 保留并汇总首批 30 词，src/data/dailyWordNotes.js 保存新增 70 词；对外导出不变。通过标准化英文拼写匹配，不依赖可能变动的词 ID，不修改词库原文、音频、用户进度或学习行为。
- 现有 WordCard 的“显示提示”消费结构化内容；每组显示适用范围、辨析、原创例句和可点击的参考链接。look/see/watch、hear/listen、bring/take、come/arrive、tired/sleepy、new/recent、common/ordinary 标为“易混词辨析”，不伪装为可直接替换的近义词。词头、构词公式和例句目标词继续加粗；未覆盖词保留基础提示。
- 来源链接使用新窗口及 noopener/noreferrer；收起提示时使用 aria-hidden 和 inert，防止隐藏的链接进入键盘焦点和辅助阅读顺序。
- 内容随前端打包，加载应用后查看提示无需额外请求或联网；外部参考网页需要网络。
- 不新增 API、数据库结构、用户数据字段或迁移；发布前端即可生效。

## 后续扩充规则

1. 从现有基础词库选词，明确具体词义、词性和比较范围。
2. 核验近义关系、用法和构词；说明资料不足的部分，保持 draft 状态，不填充猜测。
3. 编写原创中文辨析及双语例句，登记来源与核对日期，再改为 source-checked。
4. 将词映射到词组及可选构词资料；确保构词的 base/derived 与本词匹配。
5. 运行内容完整性、来源、前缀顺序、多义词边界和未核验不展示的测试；浏览器检查手机阅读及来源链接。

## 下一阶段方向与接手顺序

### 1. 按批次扩到 300 词，再到 500 词

- 当前基线为 100 词、56 组辨析、47 词构词／词族说明。下一阶段先覆盖 300 个常见基础词，再视内容质量扩到 500；每批新增 50–100 词，独立核对与验收。
- 优先补日常动作、学校／家庭、工作／出行、情绪及常见形容词，再推进四六级和备考词。沿用既有词条，不能仅凭原分类标签判断词频，也不能把批次规模称作权威词频排名。
- 优先补有实际辨析价值、适合初学者的关系。近义、易混及词族保持区分，不为达到数量给每个词强配近义词或构词分析。
- 新批次放在独立数据文件，通过 coreWordNotes.js 汇总。保留已有 100 词及来源，不覆盖之前已核验的内容。

### 2. 完善内容质量和覆盖率记录

- 每组继续核对具体词义、词性、搭配及近义词替换边界；每组保留两条原创双语例句、参考来源、核对日期和审核状态。
- 先做好英语词基与常见前后缀。引入拉丁／希腊词根或历史词源前，另找能够直接支持该分析的词源资料，不能根据字母相似推断。
- 目前 source-checked 只表示本轮参考核对。后续可增加独立语言审校流程，逐条确认前不能宣称已由专家审核。
- 维护内部覆盖率报告：分别统计已有词条、辨析、构词、待核验项及各分类覆盖情况；不把缺失资料显示成错误结论。

### 3. 扩展例句高亮的词形支持

- 当前例句按完整英文词、忽略大小写匹配目标词，已支持 helpful/useful 等原形加粗。
- 下一步按例句显式标注已核验的复数、过去式等词形，例如 buy/bought；不要依赖截取词干或子串匹配，避免把不相关单词加粗。
- 保持学生已确认的样式：词头、构词公式和例句目标词加粗，解释文字保持常规字重；沿用 WordCard 和现有提示区域。

### 4. 扩充后的验收与发布

- 每批更新内容测试的预期覆盖数，同时验证所有词均存在、来源可追溯、构词映射正确、草稿与缺失来源不会展示；不能只修改数量断言。
- 浏览器抽查本词构词、词族拓展、近义、易混、多义词及未覆盖词，检查手机长文本、折叠焦点及目标词加粗。
- 单纯扩充内容只需发布前端；本次提交还包含收藏云同步改动，整包首次上线必须同步发布 Worker 与前端，详见 learning-trust.md。无需新增数据库迁移。
- 上线后用真实登录流程核验收藏新增／取消、刷新恢复、离线重试和账号切换。当前交接记录只证明本机验收通过，不代表已完成生产验收。
