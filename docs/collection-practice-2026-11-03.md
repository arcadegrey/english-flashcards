# 个人定向巩固训练（2026-11-03）

状态：本地实现已完成，按用户要求提交至本地 Git，尚未推送或部署。本次不需要 D1 迁移，也不新增环境变量。

## 使用流程

- 错题本、我的收藏、今日复习提供“定向练习”，范围取点击时搜索筛选后的有效词条。集合里的模式菜单也可直接进入对应题型；背单词入口沿用原有行为。
- 选择测验、例句填空、听音拼写、单词配对、句子听写复用原有真实练习组件。出题和备选词只取所选词表；选择、填空、配对至少需要两个不同单词，例句题型还需可用例句。不会从全库补足。
- 每组最多 20 次答题，可提前结束。答对后原集合成员和复习计划照常更新，但本组捕获的词表保持不变；“再练一组”也保留该范围。
- 每个账号、来源、题型分别保存一份本机草稿。题型卡继续旧草稿；“按当前列表重新开始（替换草稿）”才替换该题型。列表已经清空时仍可进入未完成草稿。
- 草稿不跨设备同步。完成成绩使用现有账号成绩队列，支持离线保存、联网补传及其他客户端恢复；普通测试的范围和草稿独立保留。

## 数据与权限

`shared/collectionPractice.js` 定义三个来源和紧凑来源元数据。`src/utils/collectionPractice.js` 将来源与排序后的词条 ID 做 SHA-256 快照；完整 ID 列表只保存在本机草稿 `flashcards_collection_exam_draft:<owner>:<source>:<mode>`，最多 10000 词。继续时校验快照并按 ID 加载权威词条，失效、退役、缺失或语境识读词不静默替换。账号自己的自定义词可参与本机练习，云端是否接收仍遵循现有权威词库校验规则。

完成记录沿用 `category=all`、`scope=all`，新增可选 `focus={source,key,wordCount}`，不改变旧字段枚举、成绩表或评分规则。Worker 仍从规范词库重算答案；来源元数据用于标注范围，并不是服务端证明用户当时集合成员的证据。普通旧成绩无需迁移，合并旧客户端的重复记录时尽量保留已知来源。

混合定向答题记入全局测试统计，不计入当前无关词类的计划目标。学习状态、错题、复习安排及既有学习事件继续更新。老师按现有班级权限查看成绩与答题内容；教师接口将私人 `focus` 转成通用 `practiceKind=collection`，不暴露收藏等来源或快照标识。周报汇总保持原有口径。

准备请求在离开页面或切换账号时失效，不能晚到导航或写入另一账号。创建/替换草稿须在词表和页面代码就绪且账号仍匹配后原子写入；写入失败保留旧草稿并提供重试。浏览器前进/后退仅恢复当前账号、相同来源/题型/快照的有效草稿。已结束或不可用的历史入口提示返回集合。

## 结构与发布

`useCollectionPractice` 管理准备、续答、重开和模式切换；`CollectionPracticeView`、`CollectionAssessmentPage` 复用 AppLayout、测试页卡片、按钮及练习组件。普通测试与定向测试共用 `ExamModeGrid` 和题型配置。纯例句挖空方法移到 `shared/sentenceBlank.js`，旧出口保留。

定向工具和页面按需加载，Vite 只将小型共享方法及已在首屏使用的 storage 模块归入现有 shell 分组，没有放宽首屏预算。新页面不进行导航推测预载；现有 PWA 更新白名单将练习页面作为繁忙页面处理。

发布时同时部署前端与 Worker，以确保新成绩来源保存及教师接口脱敏一致；不执行数据库迁移或音频上传。回退到旧前端会忽略新的入口，本机定向草稿保留；旧 Worker 不保证保留新来源标注。
