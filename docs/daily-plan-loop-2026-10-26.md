# 今日学习计划闭环交接（2026-10-26）

## 本轮范围

阅读完成、考试答题日汇总及基础完成总结在此前版本已经存在。本轮补齐实际缺口，保留原有学习算法、词库、用户历史、路由与共享 AppLayout／Sidebar／Topbar，不新增页面或导航样式。

### 每日任务判断

- `src/utils/dailyPlan.js` 统一判断到期复习、词汇目标、阅读和考试巩固，依次推荐；有阅读内容但缺少推荐文章对象时，仍进入阅读选择，不再因为测试已完成而提前显示“闭环完成”。
- 词库剩余不足日目标时，用“今日已有进度 + 剩余可学量”作为本日可达到的目标上限，卡片说明原因；不修改保存的每日目标或词库偏好。词库已用尽时不会要求继续完成不存在的新词。
- 无阅读或可测词汇时，卡片明确说明，相关按钮不再空点；这些暂不可用的任务不阻塞其他可完成任务。全新空内容且无学习记录、尚未加载或加载失败时，不显示完成总结和日任务庆祝。
- 主按钮明确显示开始复习／去背单词／开始阅读／开始练习／查看统计；加载失败可原地重试准备词库。
- 有学习记录落在未载入分片时，今日计划先补齐完整词库，再判断复习、完成状态及明日安排。没有此类记录的新账号继续只加载启动词库；非全部计划沿用完整分类加载。

### 完成总结与明日预告

- 沿用既有完成面板与白蓝样式，展示当前计划词汇进度、阅读篇数、巩固题数及有效正确率；没有答题时不虚构 0% 正确率。
- 完成后展示北京时间的明日日期、预计待复习数（含到时仍未完成的复习）、当前词库剩余允许的新词目标，以及可用阅读／巩固目标。
- 预测使用当前有效学习词的复习安排，排除退役 ID、去重、忽略无效日期；不预写明日进度或复习计划。未初始化的既有学习词与今日复习入口的处理一致。
- 提供真实“查看学习趋势”和“调整计划”按钮；调整计划仍修改既有当前计划，不承诺另存一个只在明日生效的计划。
- 预告是当前记录下的估算，用户继续学习、同步或调整计划后会变化。跨过北京时间午夜时，原总结消失，新一天进度与推荐自动更新，旧历史日期保留。

## 分词库日巩固进度

新增可选的 `studyHistory[].examByCategory`，保存在已有 JSON 日汇总中，无新增 D1 列或表：

```json
{
  "date": "2026-10-26",
  "examQuestionsAnswered": 5,
  "examQuestionsCorrect": 4,
  "examByCategory": {
    "ielts": { "answered": 5, "correct": 4 }
  }
}
```

- 仅接受 daily／cet4／cet6／toefl／ielts 五个当前计划词库；“全部单词”继续读取原全局日计数。每次有效答题更新一次全局计数和当前计划词库计数；不再次统计保存一组测试成绩的动作。
- 计数按北京时间归日，非负整数，正确数不大于答题数；原单词、阅读和其他日字段保留。
- 新设备可通过现有 `/api/progress` 恢复分词库的 5 题日任务。学习缓存、账号切换及 expected-user 校验保持原有隔离机制。
- 旧 `flashcards_plan_exam_activity` 本机缓存继续兼容；启动、恢复本账号缓存及同步时，将其中明确记录的分类计数按原日期接入日汇总，不需要再答一题。重复接入不增加计数；新答题时才增加一次。不同日期不混入当天。
- 旧日汇总没有分类明细时，不推断或平分到某个词库；旧数据保持原样，原设备已有分类缓存仍可用于显示。这不是对全部历史答题逐题重建。
- 多设备和重复上传沿用原有**最大计数合并**，不声称能精确相加两台离线设备同一天的所有独立活动。
- Worker 在版本冲突时合并；旧客户端即便带准确 `baseUpdatedAt`，对保留的日期省略新字段也不会抹掉已有分类计数。明确清空整个历史列表仍保持原清除行为。
- 新字段属于学习日进度，不改变服务端测试评分、作业首次成绩或已发布快照。

## 保留的统计口径

本轮沿用既有词汇目标计数：全部计划使用原日练词计数，分类计划按当日有复习时间的不同词条统计；没有把旧“练过”数据推断为“首次见词”。总结文案改为“词汇目标／词汇进度”，不再把该值写成“今天新增”。未来如定义严格的首次学习指标，应另建有来源的事件或时间字段，并单独处理旧数据。
