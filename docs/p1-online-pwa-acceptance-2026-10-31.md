## 历史 PWA 升级与离线恢复：23 项通过

最终在新的隔离浏览器中完整复验：旧版基线 4 项，升级和离线恢复 19 项。

1. 旧客户端真实激活 SW，只有四种题型，预缓存不含独立阅读字典或听写代码；A1 文章复现 44 词旧分母。通过 UI 保存阅读答案和一组测验历史，同时建立真实单词认识／复习记录。
2. 切换静态构建后调用现有注册的标准 `update()`，等待新 Worker 完成激活，正常刷新进入新版。没有清缓存或伪造控制器；新版五种题型可见，阅读分母从 44 修正为 45，原阅读答案仍在 UI 选中。
3. 升级前后的旧成绩、阅读草稿、认识／已学／错词／复习状态、自定义词和 guest owner 按存储值逐项比较，一致；原成绩 ID 不变，原测验历史仍可查看。
4. 新版听写输入后断网刷新，原输入和答题数恢复；未缓存录音只报错，保留输入且不记错。离线结束听写追加一条成绩，保留旧测验记录；阅读完整字典仍可离线使用。
5. 离线修改阅读答案，恢复网络再刷新，答案与两条历史均保留，没有重复成绩。最终完整复验无未捕获应用错误。

初次分段检查曾在“新版预缓存已写入、Worker 尚未完成激活”时过早刷新，读取到旧页面；另有遮罩中心点击被弹窗挡住、动画期间读文本过早的脚本问题。最终脚本等待 Worker 的 `activated` 状态、等待真实文本并点击遮罩外侧，在全新旧客户端上完整复验通过。旧客户端正常更新后仍须刷新页面加载新版界面，不声称当前打开的旧界面会自动热替换。

本节证明所测历史版本在本机 Chromium 的升级和数据兼容，不关闭真实旧生产安装、跨设备或 iOS／Safari 的现场验收。
